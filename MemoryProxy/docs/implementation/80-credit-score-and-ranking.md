## 1 S8-a · 聚合层（D0 = (a) 纠正率 + 贝叶斯平滑）

### 1.1 公式与口径（写死）

- `credit = ((used − corrected) + k × baseline) / (used + k)`；缺省 `k = 5`（弱先验；显式传参可覆盖）。
- `used` / `corrected` = 按 `(asset_id, session_key)` **去重会话数**（同会话 5 次 used 只算 1 对，防水）——
  读侧复用 `rollupByAsset({ eventType })` 的 `session_count`（口径同 §3.5），**不改其语义、零 DDL、不物化**。
- `baseline` = **全团队加权** `(Σused − Σcorrected) / Σused`（**不是**"各资产平均的平均"）。

### 1.2 中性返回（不许凑数）

- `Σused = 0` ⇒ `baseline = null`；本资产 `used = 0` ⇒ `credit = baseline`（可能为 null）；
- **两者皆 null ⇒ `credit = null`**——调用方**不得**自行取 0.5（"凑一个看起来完整的公式"被明确禁止）。

### 1.3 可解释输出

`{ asset_id, credit, used, corrected, baseline }`——分子分母必须能看见（供 S8-b 与回执呈现）。

### 1.4 边界

- `corrected > used`（不变式破坏）⇒ **fail-closed：夹取 + 计数，不抛**（数据面异常不应炸调用方）；
- 排序辅助 `rankByCredit`（纯函数、**仅提供不接线**）：`credit = null` 视为"不参与"、原位不动。

## 2 语义收窄与幸存者偏差（**登记义务，不得省略**）

- **本口径回答的是"被采纳后有没有被推翻"，不是"历史上有多可靠"。**
- **幸存者偏差（如实登记）**：
  - "**从未被使用**"的资产：`used = 0` ⇒ 不产生 `credit`（中性 null），不会"冒充可信"；
  - "**被大量拒绝（`refuted`/`unconfirmed`）但偶用一次且未被纠正**"的资产：分母只有那 1 次 used ⇒
    credit 看似很高——**这是本口径的已知偏差**（根因：`refuted`/`unconfirmed` **不落行**、只累计
    进程内非持久计数，见 `status-events-repo.ts`）——因此本分**不得**被解读为"质量 / 可靠性"。

  - 信用分：来自本片 §1 的 `rollupCreditsByAsset()`；`null`/缺席 ⇒ **不渲染该列**（不得渲染成 `0`）；
  - 标黄：来源 `asset_corrected`；渲染 = `` ⚠️ 可能已过期（检测时间: <该行 created_at ISO>） ``——
    **成对**给检测时间（60 spec §5 ②）、**不得**渲染为"当前版本"（①）、本行不显示任何 version
    ⇒ 天然不依赖 corrected payload 当"当前值"（③：需要当前版本时必须从 fetched 行侧重算）；

- **开关**：`attribution.ranking.enabled`（**默认 false**；只有显式布尔 `true` 生效）——
  **关 ⇒ 渲染走既有路径、逐字节现状**（`render-golden.test.ts` 字节级对照）、**零库访问**；
